## 📖 项目简介

对于刚入门编程、全栈开发或个人运维的学习者而言，市面上的网络安全资料往往走向两个极端：要么是动辄几百页的枯燥学院派理论，要么是零碎且容易踩红线的渗透工具清单。

**《3小时速通网络安全》** 是 [**《3小时速通Linux》**](https://github.com/Stormwang815/linux-in-3-hours) 的同系列姊妹篇，坚持 **「懂攻击原理，做有效防御 · 最小但够用 · 边读边练」** 的理念：

- **彻底脱离服务器与网络**：不依赖任何 CDN、后端服务或 Docker 靶场环境，双击 `.html` 即可在电脑、手机、iPad 秒开学习。
- **边读边练，100% 零风险实操**：内置纯前端 **12 关章节联动安全靶场（Cyber Lab）** 与 **4 个嵌入式可视化微工具**，所有攻防演练均在浏览器本地安全模拟。
- **纯矢量架构图，极致轻量**：全篇 6 张攻防原理图均采用无损内联 SVG 矢量渲染，单文件便携版仅 **268 KB**，微信 / AirDrop 秒传。

## 🎯 内置交互式安全靶场 (Cyber Lab)

| 关卡 | 对应章节 | 实战任务 |
| :---: | :---: | :--- |
| **L1** | `1.2` | 审计服务器公网暴露面，收敛裸奔的 MySQL (`3306`) 与 Redis (`6379`) |
| **L2** | `1.3` | 审计 HTTP 响应头，补齐 `HttpOnly`、`SameSite` 与 `CSP` |
| **L3** | `1.4` | 拆解 Base64 凭证字符串，揪出误把编码当加密导致的明文泄露 |
| **L4** | `2.1` | SQL 注入攻防双演练：体验万能密码绕过并切换参数化查询根治 |
| **L5** | `2.2` | XSS 留言板修复：淘汰 `innerHTML`，改用安全纯文本输出 |
| **L6** | `2.3` | 阻断钓鱼页 CSRF 跨站转账攻击（`SameSite` + `CSRF Token`） |
| **L7** | `2.4` | 排查订单 API 水平越权（IDOR），补全服务端归属权校验 |
| **L8** | `2.5` | 拦截 `../../etc/passwd` 路径遍历与 `.jpg.php` 双后缀恶意上传 |
| **L9** | `3.1` | 迷你终端实战：配置 `ufw default deny incoming` 与最小端口放行 |
| **L10** | `3.2` | 钓鱼邮件火眼金睛：从 3 封高仿真邮件中识破伪造域名与双后缀木马 |
| **L11** | `3.3` | Nginx 生产日志应急取证：锁定探测 `.env` 与发起 SQLi 的攻击源 IP |
| **L12** | `3.4` | 代码与配置安全审计综合关：揪出 `DEBUG=True`、硬编码 Key、MD5 与 SQL 拼接 |

> 除 12 关章节联动闯关外，还可随时一键切换至 **「自由沙盒」**，本地安全测试 Base64 编解码、URL 编码与 SHA-256 哈希。

## ❓ 常见问题

**Q：打开 `index.html` 需要安装 Node.js、Python 或启动本地 Web 服务器吗？**  
不需要。所有样式、脚本、纯 JS SHA-256 算法、矢量图解与交互靶场均已 100% 本地化，直接双击 `index.html` 即可在任意现代浏览器中完整运行。

**Q：如何搭配《3小时速通Linux》一起学习？**  
建议先花 3 小时通关 [**《3小时速通Linux》**](https://github.com/Stormwang815/linux-in-3-hours) 掌握基础命令与服务器操作，再来学习本教程，尤其是 `PART 03` 的 SSH/UFW 加固与 Nginx 日志排查会事半功倍。
